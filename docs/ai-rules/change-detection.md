# 规范变动识别机制（通用）

> 本文件为工具无关的通用规则，适用于 Claude Code / Cursor / Windsurf / Kiro / Trae / Copilot 等所有 Vibe Coding 工具。
> 各工具的接入方式见文件末尾「各工具接入说明」。

---

## 触发条件

在任何对话中，检测到以下任一信号时，**必须立即停止当前任务**，不得继续生成代码：

- 用户指令与项目现有规范文件存在矛盾
- 对话中出现变动性措辞：「改为」「不用了」「换成」「调整一下」「去掉」「新增约束」「架构变了」等
- 生成代码过程中发现规范文件与实际需求不一致
- 用户提出的方案与已确定的技术栈、架构设计、核心约束存在冲突

---

## 停下后的固定输出格式

检测到变动信号后，立即输出以下内容，**不得跳过任何一项，不得继续生成代码**：

```
## 检测到规范变动，任务暂停

### 变动内容
[一句话描述发现了什么变动]

### 影响范围
- 涉及规范文件：[哪个规范文件的哪个章节]
- 涉及 Step 文件：[哪些 Step 文件需要同步调整，如无则填"无"]
- 涉及已生成代码：[哪些已完成代码可能需要返工，如无则填"无"]

### 当前规范（变动前）
[引用现有规范原文]

### 建议更新为
[建议的新规范内容]

---
请确认以上变动是否正确，是否需要同步更新到规范文件？
确认后我将继续执行当前任务。
```

---

## 规范更新原则

- 用户确认变动后，由 TL 负责更新对应规范文件
- **其他角色不得自行修改任何规范文件**
- 规范文件更新完成并告知后，当前任务方可继续

## 各工具接入说明

### Claude Code
已内置于根目录 `CLAUDE.md`，无需额外操作。

### Cursor
在 `.cursor/rules/change-detection.mdc` 中引用本文件内容，设置 `alwaysApply: true`：
```
---
alwaysApply: true
---
[粘贴本文件正文内容]
```

### Windsurf
粘贴本文件正文内容到 `.windsurfrules` 文件末尾。

### Kiro
已拆分为 `.kiro/steering/change-detection.md`（项目级）和 `~/.kiro/steering/global-change-detection.md`（全局级），无需额外操作。

### Copilot
粘贴本文件正文内容到 `.github/copilot-instructions.md` 文件末尾。

### Trae / Codex / 其他工具
将本文件正文内容粘贴到对应工具的系统提示词或 Rules 配置中。
