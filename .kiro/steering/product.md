# 产品概述

FIN-Core 是面向银行、支付、小贷等金融场景的**账务核心系统**，实现完整的复式记账链路。

## 核心能力

- **多级科目树**：六大类科目（资产/负债/权益/共同/成本/损益），仅末级科目允许记账
- **双子账户**：每个账户内建"可用"与"冻结"子账户，实现资金物理隔离
- **记账引擎**：SpEL 规则驱动，支持实时 / MQ 异步 / 缓冲汇总三种入账模式
- **辅助核算**：客户 / 项目 / 合同等多维核算维度，凭证层自动关联
- **完整链路**：业务流水 → 凭证 → 分录 → 明细账 → 余额更新 → 日终核算（EOD）
- **日终核算**：五阶段 EOD（切日 → 存量清理 → 余额快照 → 试算平衡 → 归档）

## 目标用户

系统内部服务调用（Facade 接口），以及管理后台运营人员（accounting-admin BFF）。
